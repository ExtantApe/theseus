# Decisions

Choices the owner has made, newest first, with the date each was made. Later work follows them without asking again. Bigger design choices have their own notes in `docs/adr`, and plans live in `docs/ROADMAP.md`.

- **2026-11-09 · An impact view, alongside the list.** The owner asked for project buckets with drag and drop, ordered by impact and effort, top five each, and "don't get rid of our existing view". His choices: buckets are categories; effort comes from the size estimates (`~15m`), so he rates impact only, and Claude fills in only missing sizes; a Focus column holds the top item from each category, ranked against each other ("so I can either work project specific or just imperative specific"). Impact is a plain field on the item's line, `impact:high` (Claude's suggestion) or `impact:high*` (his, which Claude never changes). Finishing an item there leaves it in place marked completed, and the next one joins only when he asks. Order dragged in the view is the view's own; dragging to another bucket changes the category. He also allowed Claude to rate unrated items and fill missing sizes during /morning and /weekly; that RULES.md change waits for his yes in a session.
- **2026-11-08 · Intake from other tools needs the user's yes.** The owner's words: "Build it; yes before joining". Another tool (first, a console app with action items from meeting notes) appends JSON Lines to `data/intake/<tool>.jsonl` and never edits the list or the Notes. `engine/tools/intake.py` reads it; new items are offered to the user and only accepted ones join the master list. Not the Notes inbox, because that is the user's own words. Wiring it into the workflows (RULES.md) waits for the owner's yes in a session.
- **2026-11-07 · Copyright.** `LICENSE` reads "Copyright (c) 2026 EXTANT APE". In prose the org is written EXTANT APE; GitHub URLs keep `ExtantApe`. The leak check allows that exact line through `scripts/leak-allow.txt`.
- **2026-11-07 · Name every way data leaves the Mac.** The manifesto lists each one: Claude Code, connectors you turn on, Apple's own sync, and a wall display if you connect one. Anything new that sends data off the Mac is named there first.
- **2026-11-07 · iPhone plans** (not started; details in `docs/ROADMAP.md`). The encrypted backup uses a recovery key you keep, and Theseus suggests saving it in Apple's Passwords. First run suggests iCloud backup, and staying offline is a choice. The backup covers `config.json`, `profile.md` and `data/`. The lockdown button hides and locks, replaces what the Today and Master List notes show, and warns when FileVault is off.
- **2026-11-06 · The wall display is a Pi your Mac sends to.** See `docs/adr/0008-wall-display-sends-to-a-pi.md`.
- **2026-11-04 · Theseus and Ariadne stay separate apps.** Merging them (Shannon) is an idea on the roadmap only.
