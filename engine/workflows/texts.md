Arguments: "$ARGUMENTS". Run `python3 engine/tools/imsg.py --fresh missed --days N` where N is the number in the arguments (default 7). Add `--groups` if the arguments mention groups.
Present people first, then groups. One line each: who · waiting how long · gist · ❓ if they asked something.
Then offer: "Want to knock some out? Pick names or say 'sprint'." For a sprint, prep the 3–5 easiest in as-if-they-asked mode (engine/RULES.md §6–7).
